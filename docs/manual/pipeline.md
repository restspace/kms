# Pipeline

**Sidebar:** Pipeline

An organisation-wide kanban board for tracking speaker or sponsor **prospects** — people you're
courting before they've submitted or agreed to anything — separate from any single event's
submissions.

## Columns

One column per stage: **Identified, Researching, Contacted, Interested, Confirmed, Declined**.
Confirmed and Declined are treated as closed/terminal stages.

## Adding someone

**+ Enroll** opens a dialog to search your organisation's full contact directory and add someone
to the board with a starting stage, an optional 0–100 score, and a rationale note.

## Moving a prospect

- **Drag a card** to a different column — the column highlights as you drag over it.
- Or use the **"Move to stage"** dropdown on the card itself — either method records the same
  history entry, so it doesn't matter which you use.
- Moves apply immediately and roll back with an error message if the save fails.

## Card detail

Clicking a card opens a drawer with:

- Full contact info.
- A stage dropdown (same effect as dragging).
- **Add to event** — a picker plus an **Add** button that enrols this prospect into a specific
  event, carrying their profile details across.
- A note composer.
- A full, timestamped activity log covering enrollment, every stage change, and every note.
- **Remove from pipeline** — deletes the card only, not the underlying contact; asks for
  confirmation first.
- **Open in directory** — jumps to this person's full record in the org-wide contact directory.
