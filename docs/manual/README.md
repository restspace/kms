# User Manual

A plain-language guide to running your event's call for speakers, reviewing submissions,
building the agenda, and keeping speakers on track. This is the manual for the people actually
using the app day to day — organisers, reviewers, and speakers — not a technical spec.

> Looking for the technical specification instead? See [../README.md](../README.md).

## How this manual is organised

- **Workflow guides** — narrative walkthroughs of a task from start to finish, for when you want
  to know *how to get something done*.
- **Screen reference** — one page per item in the admin sidebar, describing every non-obvious
  control on that screen. For when you want to know *what a particular screen does*.
- **Lifecycle guides** — how one record (a contact, a submission, or the event itself) moves
  through the whole app over time, cutting across several screens.

## Who does what

- **Organiser** — sets up the event, builds the form, reviews and decides, schedules the
  agenda, chases speakers for missing information. Has access to everything in this manual.
- **Reviewer** — invited to score a batch of submissions. Only sees the [Review](review.md)
  workspace with the submissions assigned to them.
- **Speaker** — submits a proposal, and if accepted, completes their profile and any tasks
  through the [speaker portal](speaker-portal.md).
